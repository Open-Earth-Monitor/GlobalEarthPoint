# Download ICESat-2 ATL08 version 6 Data

## 1. Visit the GEDI Ecosystem LiDAR Website

Go to: [https://search.earthdata.nasa.gov/search?q=ATL08%20V006](https://search.earthdata.nasa.gov/search?q=ATL08%20V006)

## 2. Log In with EarthData Account

Store your EarthData login credentials in a `.netrc` file in your home directory:

```bash
cat ~/.netrc
```

Add the following lines (replace with your actual credentials):

```bash
machine urs.earthdata.nasa.gov
login youraccountname
password youraccountpassword
```

## 3. Select ICESat-2 Files

Browse and select the ICESat-2 ATL08 version data files you want to download from the website.

## 4. Generate Download Links

Get the direct download link(s) and use the following `wget` command:

```bash
wget https://n5eil01u.ecs.nsidc.org/DP5/ATLAS/ATL08.006/2025.03.02/ATL08v6_file_path -P /path/to/folder/
```

> 🔁 Replace `ATL08v6_file_path` and `/path/to/folder/` accordingly.

## 5. Create a List of Download Links

Save all the desired links in a file called `download_prompts.in`.

## 6. Run Parallel Download Script

Use GNU `parallel` to download files concurrently (e.g., 3 at a time):

```bash
cat download_prompts.in | parallel -j3
```

> ✅ Ensure `parallel` is installed (`sudo apt install parallel` on Debian-based systems).
